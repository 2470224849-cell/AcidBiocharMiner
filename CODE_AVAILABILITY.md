# Code availability statement draft

The literature-screening, main-text/supplementary-information parsing, LLM-assisted extraction, rule-based table parsing, acid/pristine sample filtering, two-table export, and evidence-based backfilling code used in this study is available at **https://github.com/2470224849-cell/AcidBiocharMiner** and will be archived at **[Zenodo DOI]** upon publication. The archived release will record the software environment, prompts, model configuration aliases, and frozen workflow parameters. Publisher article PDFs and supplementary files are not redistributed; users must obtain the source literature through the relevant publishers or lawful repositories. The model-evaluation package will include the sampling manifest, annotation protocol, structured gold-standard records, model outputs, field-matching code, and benchmark metadata needed to reproduce the reported performance metrics.
